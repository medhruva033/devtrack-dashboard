
# 🚀 DevTrack — Developer Productivity Dashboard

A responsive task management dashboard built with HTML, CSS, and JavaScript to help developers organize tasks, manage priorities, and track productivity.

## ✨ Features

- 📊 Dashboard with task statistics
- ✅ Create, complete, and delete tasks
- 🔥 High, medium, and low priority management
- 📅 Task deadlines and overdue indicators
- 📈 Productivity progress chart
- 🔎 Search and filter tasks
- 🗂️ Overview, today's tasks, upcoming, and completed views
- 💾 Persistent task storage using Local Storage
- 📱 Responsive layout for mobile and desktop

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

```bash

```

### 2. Open the project

```bash
cd devtrack-dashboard
code .
```

### 3. Run the application

Open `index.html` using the Live Server extension in VS Code.

## 💾 Data Storage

Tasks are stored in the browser's Local Storage. Data is not synced between devices or users.
